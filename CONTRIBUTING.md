# Contribuir a MindSage

Gracias por ayudar a preservar historias con respeto. Antes de programar una función grande, abre una
incidencia que describa el problema, las personas afectadas y las implicaciones de privacidad.

## Flujo

1. Crea una rama corta desde `main`.
2. Añade o actualiza pruebas.
3. Ejecuta las verificaciones descritas en el README.
4. Mantén las migraciones inmutables: crea una nueva versión en vez de editar una aplicada.
5. Abre un pull request pequeño con capturas cuando cambie la interfaz.

Los datos de prueba deben ser ficticios o tener una licencia y procedencia documentadas. No se
aceptarán testimonios personales reales en el repositorio.
