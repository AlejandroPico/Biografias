Acerca de MindSage

Conservar una vida es conservar una parte del mundo.

MindSage nace de una pregunta sencilla: ¿cuántas historias, voces y enseñanzas desaparecen porque nadie llegó a sentarse a escuchar?

El proyecto

Memoria personal, familiar e histórica

La aplicación ayuda a entrevistar a padres, abuelos, familiares, amistades y vecinos; relaciona personas, acontecimientos, lugares, fotografías, documentos y consejos para construir biografías profundas y navegables.

Esta versión utiliza almacenamiento local porque se publica gratuitamente en GitHub Pages. La arquitectura Spring Boot y el modelo de datos preparan el paso posterior a cuentas, permisos, sincronización y preservación en servidor.

  • Privacidad y consentimiento por finalidad.
  • Fichas incompletas para personas mencionadas y reclamación futura.
  • Exportación para que ninguna memoria quede cautiva.
  • IA futura únicamente con autorización explícita y siempre identificada.

Privacidad por diseño

Una vida no es un conjunto de datos cualquiera.

MindSage separa claramente propiedad, acceso, publicación, investigación y cualquier posible uso de inteligencia artificial.

01

Consentimiento granular

Publicar una historia no autoriza a clonar una voz. Cada finalidad se decide de forma independiente y revocable.

02

Privado por defecto

Una memoria nueva comienza cerrada. Su creador decide si será personal, familiar, comunitaria o pública.

03

Derecho a corregir y borrar

La persona retratada y quienes tengan legitimidad pueden pedir rectificaciones, exportación o eliminación.

04

IA siempre declarada

Cualquier voz, imagen o conversación sintética debe identificarse de forma visible y conservar trazabilidad.

05

Datos portables
